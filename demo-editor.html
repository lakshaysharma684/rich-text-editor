Only bold, italic, underline, bullet list, numbered list, and clear formatting. All other buttons and their separators are hidden automatically.

This editor is intentionally minimal. Use it for product descriptions, ingredient lists, or any field where only basic formatting makes sense.

Usage — toolbarItems

Pass an array of command strings. Omit (or pass null) to show all buttons — no behavior change for existing editors.

new RichTextEditor('#indications-rte', {
  toolbarItems: [
    'bold', 'italic', 'underline',
    'insertUnorderedList', 'insertOrderedList',
    'removeFormat'
  ]
});

// Full toolbar (default — no change needed)
new RichTextEditor('#blog-editor', {
  placeholder: 'Start writing...',
  enableAutoSave: true
});
