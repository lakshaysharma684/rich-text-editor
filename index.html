Welcome to Rich Text Editor v1.5.0.

This version adds toolbarItems for restricting visible buttons, and automatic system dark mode.

What's new:

  • toolbarItems — pass an array of commands, only those buttons render.
  • System dark mode — auto-matches OS preference, respects manual toggle.
  • Improved editor layout — cleaner toolbar, better typography, focus ring.
